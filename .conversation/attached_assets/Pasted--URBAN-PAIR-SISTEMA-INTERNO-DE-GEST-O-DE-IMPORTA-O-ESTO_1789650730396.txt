# URBAN PAIR — SISTEMA INTERNO DE GESTÃO DE IMPORTAÇÃO, ESTOQUE, VENDAS E LUCRO

Quero que você desenvolva um sistema web completo, profissional, moderno e funcional chamado **Urban Pair**.

O sistema será uma plataforma **privada e interna**, utilizada somente por mim e pelos meus parceiros, para administrar toda a operação da Urban Pair: produtos, fornecedores, compras na China, pedidos, importações, logística, rastreamento, estoque, vendas, custos, câmbio, lucro e análises financeiras.

Não quero apenas uma interface visual/mockup. Quero um sistema realmente funcional, com banco de dados persistente, CRUDs reais, cálculos reais, autenticação, integrações reais quando tecnicamente possíveis e tratamento de erros.

---

# 1. OBJETIVO PRINCIPAL

O sistema deve centralizar toda a operação da Urban Pair em um único lugar.

Fluxo principal:

**Fornecedor → Catálogo → Produto → Pedido → Compra na China → CSSBuy → Armazém → QC → Consolidação → Envio internacional → Rastreamento → Brasil/EUA → Estoque → Venda → Receita → Lucro**

O sistema deve permitir acompanhar cada produto desde a pesquisa/compra até a venda.
